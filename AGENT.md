# Code Review Instructions

- Respond using bullet points only.
- Do not write an introductory or closing paragraph.
- Begin each bullet with one of: `BUG:`, `RISK:`, `STYLE:`, or `OK:`.
- Cite a line number when the supplied code includes line numbers.
- Explain the concrete effect of every reported issue.
- Do not invent problems; use one `OK:` bullet when no actionable issue exists.
